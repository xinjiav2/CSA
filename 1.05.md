## Popcorn Hack (In-Class)

**Task:** For each expression, predict the output, then verify with code.

### Predictions (written before running)

| # | Expression | Prediction | Reasoning |
|---|------------|------------|-----------|
| 1 | `10 / 4` | **2** | Both operands are `int` → integer division truncates toward zero |
| 2 | `(double)10 / 4` | **2.5** | Cast happens first → floating-point division |
| 3 | `(int)7.8` | **7** | Narrowing cast truncates toward zero (drops the decimal) |
| 4 | `(int)(7.8 + 0.5)` | **8** | Add 0.5 then truncate → standard positive rounding |
| 5 | `Integer.MAX_VALUE + 1` | **-2147483648** | Overflow wraps from MAX to MIN |

### Completed Verification Code

```java
public class CodeRunner1_PopcornHack {
    public static void main(String[] args) {
        // Q1: integer division
        System.out.println("Q1: " + (10 / 4));

        // Q2: cast before divide
        System.out.println("Q2: " + ((double)10 / 4));

        // Q3: truncate
        System.out.println("Q3: " + ((int)7.8));

        // Q4: round positive
        System.out.println("Q4: " + ((int)(7.8 + 0.5)));

        // Q5: overflow
        int x = Integer.MAX_VALUE;
        System.out.println("Q5: " + (x + 1));
    }
}
CodeRunner1_PopcornHack.main(null);
```

### Actual Output
```
Q1: 2
Q2: 2.5
Q3: 7
Q4: 8
Q5: -2147483648
```

**Explanation of each result**
1. `10 / 4` – both ints → result is int 2 (fraction discarded).
2. `(double)10 / 4` – cast promotes 10 to 10.0 first, then 10.0 / 4 produces 2.5.
3. `(int)7.8` – narrowing conversion truncates toward zero → 7.
4. `(int)(7.8 + 0.5)` – 8.3 truncated → 8 (classic positive rounding).
5. `MAX_VALUE + 1` – 32-bit int overflow wraps to `MIN_VALUE` (-2147483648).

## Homework Hack

**Task:** Implement three methods that demonstrate correct casting.

### Method 1 – averageAsDouble

**Prediction / Design**
- Must avoid integer division.
- Cast at least one operand (or the sum) to `double` before dividing by 2.
- Expected: `averageAsDouble(5, 10)` → 7.5

```java
public static double averageAsDouble(int a, int b) {
    // Cast the sum (or one operand) to double before dividing.
    // This prevents the integer-division result of (a + b) / 2.
    return ((double)a + b) / 2.0;
}
```

### Method 2 – percentScore

**Prediction / Design**
- Need a floating-point result in the range 0.0–100.0.
- Guard against division by zero.
- Expected: `percentScore(7, 10)` → 70.0; `percentScore(0, 0)` → 0.0

```java
public static double percentScore(int correct, int total) {
    // Edge case: avoid division by zero
    if (total == 0) {
        return 0.0;
    }
    // 100.0 forces floating-point arithmetic
    return (100.0 * correct) / total;
}
```

### Method 3 – nearestInteger

**Prediction / Design**
- Positive values: add 0.5 then truncate.
- Negative values: subtract 0.5 then truncate.
- Expected: 5.4 → 5, 5.5 → 6, −5.4 → −5, −5.5 → −6

```java
public static int nearestInteger(double value) {
    // Different offset needed for positive vs negative numbers
    if (value >= 0) {
        return (int)(value + 0.5);   // round half up for non-negative
    } else {
        return (int)(value - 0.5);   // round half “away from zero” for negative
    }
}
```

### Complete Test Runner

```java
public class CodeRunner2_CastingPractice {

    public static double averageAsDouble(int a, int b) {
        // Cast prevents integer division
        return ((double)a + b) / 2.0;
    }

    public static double percentScore(int correct, int total) {
        if (total == 0) {
            return 0.0;               // edge-case guard
        }
        return (100.0 * correct) / total;
    }

    public static int nearestInteger(double value) {
        if (value >= 0) {
            return (int)(value + 0.5);
        } else {
            return (int)(value - 0.5);
        }
    }

    public static void main(String[] args) {
        // averageAsDouble
        System.out.println("Average of 5 and 10: " + averageAsDouble(5, 10));   // 7.5
        System.out.println("Average of 3 and 4: " + averageAsDouble(3, 4));     // 3.5

        // percentScore
        System.out.println("80 out of 100: " + percentScore(80, 100) + "%");    // 80.0%
        System.out.println("7 out of 10: " + percentScore(7, 10) + "%");        // 70.0%
        System.out.println("0 out of 0: " + percentScore(0, 0) + "%");          // 0.0%

        // nearestInteger
        System.out.println("Round 5.4: " + nearestInteger(5.4));                // 5
        System.out.println("Round 5.5: " + nearestInteger(5.5));                // 6
        System.out.println("Round -5.4: " + nearestInteger(-5.4));              // -5
        System.out.println("Round -5.5: " + nearestInteger(-5.5));              // -6
    }
}
CodeRunner2_CastingPractice.main(null);
```

### Actual Output
```
Average of 5 and 10: 7.5
Average of 3 and 4: 3.5
80 out of 100: 80.0%
7 out of 10: 70.0%
0 out of 0: 0.0%
Round 5.4: 5
Round 5.5: 6
Round -5.4: -5
Round -5.5: -6
```

**Explanation of casting choices**
- `averageAsDouble` – `((double)a + b) / 2.0` forces floating-point arithmetic so the fractional part is kept.
- `percentScore` – multiplying by the double literal `100.0` promotes the whole expression; the zero-total guard prevents a runtime exception.
- `nearestInteger` – the classic CED rounding pattern: add 0.5 (or subtract 0.5 for negatives) then truncate with `(int)`.
